# kmd Support

kmd is a local-first Markdown editor for iPhone, iPad, and Mac.

## Open and save files

Use the folder button to open UTF-8 Markdown or plain-text files from Files. Use the save button to update the current document or export a new `.md` file.

## Live outline and preview

The outline shows headings, section word counts, and each section's share of the document. Preview renders Markdown locally and updates as you type.

## Share content to kmd

Choose **Share with kmd** in another app. Open the Inbox in kmd to review and insert the captured content into the current note.

## Get help

Report a reproducible problem in the [kmd issue tracker](https://github.com/fengurt/ksa-MarkEdit/issues). Include the kmd version, iOS version, device model, and steps to reproduce. Never attach a private note unless you have removed sensitive information.
